# 从零到 FOC：八堂实验课

这一组实验不要求你先会电机学。每一课都是一个**能跑的脚本**：改参数、看图、看终端里的数字，
自己把结论"看出来"，而不是背公式。

全部实验共用项目里的相域电机模型（`sim/plant.py`）和 SimpleFOC 闭环（`sim/foc.py`），
所以你在第 6 课手写的 FOC，和第 8 课调用的库，是同一台电机、同一套工况。

## 课程地图

| # | 实验 | 你会看到 | 关键结论 |
|---|------|----------|----------|
| 01 | [三相电流与旋转磁场](t01_three_phase.py) | 三相正弦 → αβ 平面上的一个圆 | 三相交流等效于一个匀速旋转的矢量 |
| 02 | [Clarke / Park 变换](t02_clarke_park.py) | 同一个圆，换成转子视角后变成两条直线 | 跟着转子转，交流就变成直流 |
| 03 | [反电动势与转矩](t03_bemf_torque.py) | EMF 波形、kt 实测、机械特性 | Te = kt·iq；高速没劲是因为 EMF 顶住了母线 |
| 04 | [开环 V/f](t04_openloop_vf.py) | 能转，也会失步，而且驱动器不知道 | 没有角度反馈就没有转矩控制 |
| 05 | [六步换相 BLDC](t05_sixstep_bldc.py) | 方波电流、转矩 12.8% 脉动 | 6 个离散矢量逼近连续矢量，必然抖 |
| 06 | [电流环](t06_current_loop.py) | 120 行手写 FOC 与库几乎重合 | 带宽 ≈ Kp/L，I 用来抵消反电动势 |
| 07 | [调制：正弦 vs SVPWM](t07_svpwm.py) | 马鞍形占空比、+15.5% 电压利用率 | 零序注入是"白送"的母线电压 |
| 08 | [速度环与位置环](t08_cascade_loops.py) | 阶跃、负载扰动、定位 | 级联带宽一级比一级低；限幅决定加速度 |

## 怎么跑

```bash
conda activate motors          # 依赖只有 numpy + matplotlib

python3 tutorial/t01_three_phase.py     # 单课：终端讲解 + out/t01_three_phase.png
python3 tutorial/run_all.py             # 全部：依次跑完，汇总耗时与图
```

第一次跑会自动编译 `sim/native/libfocsim.so`（需要 g++），之后复用。

图都落在 `tutorial/out/`，文件名与脚本同名。

## 建议的学法

1. **先跑再看代码**：先读终端输出和那张图，猜"为什么会这样"；
2. **再读脚本**：每个脚本里算式都写成一行行代码，没有黑盒；
3. **改参数重跑**：每课末尾的"思考题"都是可以立刻验证的，改一个数就能看到答案；
4. **对照工程实现**：`tests/test_suite.py` 是同一套东西的 22 项工程级回归测试，
   想看"这些结论怎么被固化成断言"，去读那里。

## 知识主线

```
实验 01  三相 → 旋转矢量
   ↓
实验 02  旋转矢量 → dq 直流（Clarke + Park）
   ↓
实验 03  转矩只认 iq（kt = 1.5·p·ψf）
   ↓
实验 04  没有反馈 → 开环失控（反例）
   ↓
实验 05  离散矢量 → 六步换相（粗糙但能用）
   ↓
实验 06  连续矢量 + PI → 电流环（FOC 的内核）
   ↓
实验 07  矢量 → 占空比（调制，母线利用率）
   ↓
实验 08  电流环外套速度环、位置环（伺服系统）
```

## 说明

- 模型边界：PWM 按**平均电压**建模，不含开关纹波、死区、逆变器压降；表贴式 Ld=Lq，
  无磁饱和与齿槽转矩。所以第 5、6 课里 FOC 的转矩纹波接近 0 —— 这是模型选择，
  不是算法结论。真实系统里纹波来自开关、采样与死区。
- 参数都是 24 V / 4 极对 / 2 mH 的小功率电机，可以直接在 `sim/plant.py` 的
  `MotorParams` 里改，所有实验会跟着变。
